# Phonebook

Phonebook — это учебное SPA-приложение для управления контактами, созданное в
рамках практики работы с React, Redux Toolkit и React Router. Проект
демонстрирует организацию клиентского приложения с маршрутизацией, глобальным
состоянием, асинхронными операциями и защитой маршрутов.

---

## Возможности приложения

- авторизация пользователя без backend;
- защита приватных маршрутов;
- добавление новых контактов;
- удаление контактов;
- поиск и фильтрация контактов;
- добавление контактов в избранное;
- централизованное управление состоянием через Redux Toolkit;
- работа с server state (RTK Query / async thunks в зависимости от ветки);
- отображение уведомлений через React Toastify.

---

## Архитектура проекта

Приложение построено по принципам SPA (Single Page Application). Маршрутизация
реализована с помощью React Router, а глобальное состояние хранится в Redux
Store.

В проекте разделены два типа состояния:

- **UI state** (фильтры, авторизация);
- **Server state** (контакты).

Для организации кода используются:

- Redux Toolkit slices;
- selectors;
- memoization (`useMemo`);
- memoized callbacks (`useCallback`);
- разные подходы к async логике в отдельных ветках.

---

## Ветки проекта

Проект разделён на три реализации:

---

### `main`

Базовая версия проекта без API.

Контакты сохраняются локально через `localStorage`, без взаимодействия с
сервером.

Эта версия демонстрирует:

- работу с Redux Toolkit;
- управление состоянием на клиенте;
- сохранение данных в браузере;
- базовую архитектуру SPA-приложения.

---

### `redux-async-thunks`

Версия с ручной асинхронной логикой через `createAsyncThunk`.

Используется:

- `createAsyncThunk`;
- `axios`;
- `extraReducers`;
- ручное управление loading/error states;
- CRUD-операции через HTTP (MockAPI).

Контакты синхронизируются с сервером вручную через thunk-операции.

---

### `rtk-query`

Современная версия приложения с использованием RTK Query.

Используется:

- `createApi`;
- auto-generated hooks;
- caching и invalidation через `tagTypes`;
- автоматическое управление loading/error states;
- декларативная работа с server state;
- минимизация boilerplate-кода.

RTK Query автоматически:

- кэширует данные;
- выполняет refetch после mutations;
- управляет состоянием запросов;
- генерирует React hooks.

## Цель проекта

Основная цель проекта — практика современной frontend-разработки и сравнение
подходов к работе с server state:

- ручной Redux + thunks;
- современный RTK Query подход;
- управление локальным состоянием через Redux Toolkit.

Проект позволяет на практике увидеть эволюцию архитектуры React-приложений от
ручного управления async логикой к декларативному data fetching.
